# TNNN — Tên nhiệm vụ

- **Trạng thái:** `planned` | `in_progress` | `verifying` | `blocked` | `done`
- **Mục tiêu:** một kết quả kiểm chứng được.
- **Nguồn yêu cầu:** link issue/tin nhắn hoặc mô tả ngắn; ngày.
- **Chủ sở hữu/reviewer:** tên hoặc vai.
- **Phạm vi file dự kiến:** đường dẫn.
- **Liên quan:** task phụ thuộc hoặc task gốc nếu là lỗi.
- **Source refs đã đọc:** `docs/file.md §...`, `AGENTS.md §...`, code hiện tại.
- **Điểm tiếp tục:** bước cụ thể tiếp theo, lệnh test cần chạy lại, điều kiện còn thiếu.

## Cổng trước coding

- [ ] Đã đọc tài liệu liên quan và code hiện tại.
- [ ] Đã xác định mâu thuẫn/điểm chưa rõ và cập nhật hoặc ghi quyết định.
- [ ] `spec.md`, `plan.md`, `tests.md` có nội dung cụ thể.

## Cổng kết thúc

- [ ] Acceptance trong `spec.md` đạt hoặc ghi rõ phần chưa đạt.
- [ ] Các bước `plan.md` đã đánh dấu thật.
- [ ] `tests.md` có lệnh, kết quả, ngày/môi trường; test không chạy có lý do.
- [ ] Docs chuẩn/API/schema được cập nhật nếu hành vi thay đổi.
- [ ] `handoff.md` nêu cách kiểm tra và điểm tiếp tục.
