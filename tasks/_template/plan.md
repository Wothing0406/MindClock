# Kế hoạch thực hiện

## Điểm bắt đầu

Code hiện tại, test hiện tại, môi trường/thiết bị cần, phụ thuộc.

## Các bước nhỏ

| Bước | Việc làm và file dự kiến | Điều kiện xong | Trạng thái |
| --- | --- | --- | --- |
| 1 | Tạo test tái hiện/fixture nếu có lỗi | Test đỏ đúng nguyên nhân | [ ] |
| 2 | Thay đổi tối thiểu | Hành vi khớp AC | [ ] |
| 3 | Kiểm tra liên vùng và cập nhật docs | Contract/PRD nhất quán | [ ] |
| 4 | Chạy test phù hợp + rà diff | Không còn lỗi P0/P1 trong phạm vi | [ ] |

## Rủi ro và đường lui

Rủi ro cụ thể; cách tắt tính năng/rollback hoặc phục hồi dữ liệu nếu cần. Không ghi chung chung “có thể có bug”.
