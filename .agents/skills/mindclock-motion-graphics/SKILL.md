# MindClock motion graphics

Use only for an approved asset task. Read `docs/01-product/11-canh-mo-man-va-nguon-video.md`, `docs/01-product/03-he-thiet-ke.md`, the question/rubric and asset rights first.

Upstream source: `artemnovitckii/claude-animation-skills` commit `5dbea55c23aa6a5c93dc3cfb5583840513b56b94`, MIT; copied templates and shared kit under `upstream/`. Read the original skill before use:
- `upstream/skills/minimalistic-graphics/SKILL.md`: adapt calm 2D line motion for 6-12 second MorningCard; do not copy promotional text.
- `upstream/skills/graph/SKILL.md`: adapt chart animation for progress only; values must come from real app data.

The upstream scripts produce rendered video/reel assets, not Flutter widgets, Android alarm effects, or PvP sprite animation. Do not add their Node/Python dependencies to the mobile runtime. Produce a storyboard, 9:16 video or frame sequence, still poster, captions and source manifest. Review educational accuracy, license of every ingredient, sound separately, 6-12 second duration, file size, Reduce Motion and offline fallback. Add final asset only after reviewer approval and Android playback test. Do not use the 3D/reel skills as production UI or clone another creator's recognizable style.
