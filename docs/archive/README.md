# Lưu trữ tài liệu trước production

[`2026-11/`](2026-11/) giữ nguyên 58 file tài liệu đánh số cũ (bao gồm bản web local WIP) để truy nguồn ý tưởng, quyết định, ví dụ và lịch sử DevFest. Từ 15/11/2026, chúng **không còn là nguồn chuẩn để AI coding**: nhiều file nói repo chưa có app/API, một số luật PvP/roster/XP cũ mâu thuẫn nhau hoặc chỉ mô tả web prototype đã xóa.

Nếu cần dùng một chi tiết từ archive, đối chiếu [index canonical](../README.md), mã/test hiện hành, quyền nội dung và quyết định chủ dự án. Khi chi tiết vẫn hữu ích, đưa nó vào tài liệu canonical và một task có AC/test; không trỏ code mới trực tiếp vào archive để né quyết định. Các link Markdown đã được di chuyển cơ học; đường dẫn dạng chữ thường trong ví dụ cũ có thể là lịch sử, không phải lệnh chạy hiện tại.

Tài liệu archive không bị xóa để giữ bằng chứng và khả năng giải thích vì sao sản phẩm từng chọn một hướng. Task lịch sử trong `tasks/` có thể link tới file archive tương ứng; trạng thái test của chúng giữ nguyên.
